# Returns policy / سياسة المرتجعات
Customers can return items within 14 days of purchase with the receipt. Perishable dairy and OTC pharmacy items can be returned only if damaged or expired.
Returns reasons are recorded as: damaged, wrong item, expired, changed mind.
يقدر العميل يرجّع المنتج خلال 14 يوم من الشراء مع الفاتورة. منتجات الألبان والصيدلية بدون روشتة بترجع فقط لو تالفة أو منتهية الصلاحية.
أسباب المرتجع المسجلة: تالف، منتج غلط، منتهي الصلاحية، غيّر رأيه.
